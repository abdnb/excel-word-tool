# Excel 批量生成 Word 工具

将 Excel 数据按 Word 模板批量生成文档，支持自定义字段映射。

## 快速使用

### Windows 系统

#### 方式一：直接运行 exe（推荐）
```
双击运行: dist/Excel-Word工具.exe
```

#### 方式二：从源码运行
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行程序
python gui_app.py
```

### Linux 系统

#### 方式一：使用安装脚本（推荐）
```bash
# 自动安装依赖并打包
bash install_linux.sh
```

#### 方式二：手动打包
```bash
# 1. 安装依赖
pip3 install -r requirements.txt

# 2. 打包程序
python3 build_linux.py

# 3. 运行
cd dist
chmod +x Excel-Word工具
./Excel-Word工具
```

#### 方式三：快速运行脚本
```bash
# 打包后使用
bash run_linux.sh
```

详细的 Linux 使用说明请查看：[Linux打包说明.md](Linux打包说明.md)

## 使用步骤

1. **准备模板**：创建 Word 文档，在需要填充数据的地方使用 `{{字段名}}` 作为占位符
2. **准备数据**：准备好 Excel 数据文件
3. **启动工具**：运行 exe 或 python gui_app.py
4. **添加文件**：
   - 点击"添加"选择 Excel 文件
   - 点击"浏览"选择 Word 模板
5. **配置映射**：
   - 点击"智能检测"自动设置跳过行数
   - 点击"预览列名"查看 Excel 列（确认数据行数正确）
   - 点击"分析"查看模板占位符
   - 切换到"字段映射"标签页，双击配置字段对应关系
6. **生成文档**：点击"开始生成"

## 核心功能

- ✅ 支持导入任意 Word 模板
- ✅ 可视化字段映射配置
- ✅ 智能检测 Excel 结构
- ✅ 批量处理多个 Excel 文件
- ✅ 自动匹配相似字段名
- ✅ 保存/加载映射配置

## 重要提示

**"跳过行数"设置**：
- 含义：跳过前 N 行，下一行作为列名，再下一行开始是数据
- 例如：列名在第2行 → 跳过1行
- 建议：点击"智能检测"自动设置，然后点击"预览列名"确认

**验证方法**：
- 点击"预览列名"后，检查显示的"数据行数"是否正确
- 数据行数应该等于实际数据行数（不包括标题和列名）

## 示例

**模板文件：**
```
通知书

{{部门}}：
您的 {{事项}} 已受理。
编号：{{编号}}
```

**Excel 数据：**
| 部门名称 | 事项名称 | 申请编号 |
|---------|---------|---------|
| 财务部   | 预算申请 | 2024001 |
| 人事部   | 招聘申请 | 2024002 |

**字段映射：**
- {{部门}} → 部门名称
- {{事项}} → 事项名称  
- {{编号}} → 申请编号

**生成结果：**
- 财务部_预算申请.docx
- 人事部_招聘申请.docx

## 依赖

- pandas
- openpyxl
- python-docx
- tkinter (Python 标准库)

## 使用步骤

### 1. 创建模板文件

首先运行以下命令创建一个示例模板：

```bash
python create_template.py
```

这会生成一个 `template.docx` 文件，你可以根据需要修改这个模板。

### 2. 编辑模板

打开 `template.docx`，使用以下占位符格式：

- `{{委托部门名称}}` - 会被替换为 Excel 中"委托部门名称"列的数据
- `{{受理事项名称（实施清单）}}` - 会被替换为对应列的数据
- `{{受理编号（林草为后台受理编号）}}` - 会被替换为对应列的数据
- 其他列名同理

可用的占位符（根据你的 Excel 文件）：
- `{{委托部门名称}}`
- `{{受理事项名称（实施清单）}}`
- `{{受理编号（林草为后台受理编号）}}`
- `{{承诺时限}}`
- `{{剩余工作日}}`
- `{{预警提醒}}`
- `{{受理日期}}`
- `{{承诺办结日期}}`
- `{{超时}}`
- `{{邮箱}}`
- `{{序号}}` - 自动生成的序号

### 3. 批量生成 Word 文档

确保以下文件在同一目录：
- `部门预警.xlsx` - 你的 Excel 数据文件
- `template.docx` - Word 模板文件
- `excel_to_word.py` - 主程序

运行命令：

```bash
python excel_to_word.py
```

生成的 Word 文档会保存在 `output` 目录中。

## 自定义配置

如果需要修改文件路径，可以编辑 `excel_to_word.py` 文件中的配置：

```python
EXCEL_FILE = "部门预警.xlsx"      # Excel 文件路径
TEMPLATE_FILE = "template.docx"   # 模板文件路径
OUTPUT_DIR = "output"             # 输出目录
```

## 文件说明

- `excel_to_word.py` - 主程序，执行批量生成
- `create_template.py` - 模板创建工具
- `template.docx` - Word 模板文件（需要先创建）
- `requirements.txt` - Python 依赖包列表
- `output/` - 生成的 Word 文档保存目录

## 注意事项

1. Excel 文件的前几行可能是标题，程序会自动跳过
2. 生成的文件名格式：`{部门名称}_{事项名称}.docx`
3. 如果数据中包含特殊字符，会自动替换为下划线
4. 空值会被替换为空字符串

## 故障排除

如果遇到问题：

1. 确保已安装所有依赖：`pip install -r requirements.txt`
2. 检查 Excel 文件格式是否正确
3. 确保模板文件存在且占位符格式正确
4. 查看控制台输出的错误信息
